# Student Management System

A simple Student Management System built using Java, Spring Boot, MySQL, HTML, CSS, and JavaScript.

## Features

* Add student
* View students
* Search student
* Update student details
* Delete student

## Technologies Used

* Java
* Spring Boot
* MySQL
* HTML
* CSS
* JavaScript
* Git & GitHub

## Project Structure

```text
student-management/
├── backend/
├── frontend/
└── screenshots/
```

## Database

The project uses MySQL to store student information.

## How to Run

1. Clone the repository.
2. Open the project in your IDE.
3. Configure the MySQL database.
4. Run the Spring Boot application.
5. Open the frontend in your browser.
