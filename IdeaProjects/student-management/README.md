# Student Management System

A simple full-stack Student Management System built using **Java, Spring Boot, MySQL, HTML, CSS, and JavaScript.

## Features

* Add Student
* View Students
* Update Student
* Delete Student

## Technologies Used

* Java
* Spring Boot
* MySQL
* HTML
* CSS
* JavaScript
